# 简易飞行戒指 Simple Flight Ring

一个面向 **Minecraft 1.21.1 / NeoForge** 的小型 MOD，添加 6 种材质的飞行戒指：
木 → 石 → 铁 → 金 → 钻石 → 下界合金。

## 特性

- **传统创造飞行**：佩戴（或背包内携带）有耐久的戒指时，玩家获得创造模式的飞行能力，
  双击空格起飞/降落，按住空格上升、Shift 下降，与创造模式手感完全一致。
- **仅飞行时消耗耐久**：每飞行 1 秒消耗 1 点耐久；站着不动或落地后不消耗。
- **耐久附魔延长飞行时间**：耐久附魔每级让每点耐久多飞行 1 秒
  （耐久 III 时每 4 秒才消耗 1 点耐久）。
- **经验修补（Mending）**：直接兼容原版机制，拾取经验球即可修复戒指。
- **戒指耐久耗尽后不会消失**：变为失效状态（无法飞行），仍可参与升级合成，
  也可通过经验修补或铁砧修复。
- **嵌套合成升级**：3x3 工作台外圈 8 格为对应材料，中间放羽毛（木戒指）或低一级戒指。
  - 升级时**保留附魔、自定义名称和 Lore**；
  - 升级配方**忽略输入戒指的剩余耐久**（哪怕耐久为 0 也能升级）；
  - 升级产物为满耐久的新戒指。
- **下界合金戒指**：通过**锻造台**升级——下界合金升级锻造模板 + 钻石飞行戒指 + 下界合金锭。
- **Curios API 可选集成**（非必须）：
  - 安装 Curios 后自动添加一个额外的**「飞行戒指」饰品槽位**，戒指可右键直接佩戴；
  - 未安装 Curios 时，戒指放在背包内即可生效；
  - 即使安装了 Curios，放在背包内同样生效（优先检测饰品槽位，其次背包）。
- **HUD 飞行时间倒计时**：携带可用戒指时在游戏界面显示剩余飞行时间（默认左下角），
  可在配置文件中开关与调整位置。
- **Cloth Config API 可选适配**（非必须）：安装后可在游戏内 Mod 列表点击「Config」打开配置界面，
  用滑块条实时调整 HUD 位置；未安装时直接编辑配置文件同样生效。
- **精妙背包 Sophisticated Backpacks 可选适配**（非必须）：戒指放在精妙背包内同样生效——
  背包在主物品栏、**盔甲栏（穿在背上）**、副手或 Curios 槽位中均可，支持**嵌套背包**（最深 3 层）；
  HUD 倒计时同样累加背包内戒指。
- **Allthemodium 联动**（可选，需安装 Allthemodium，见下文）：新增 ATM / 振金 / 难得素 三枚联动戒指，
  自带不毁、能量池与沿链条继承的特殊能力，以及仅限三枚联动戒指的「魔能增幅」附魔。
  **未安装 Allthemodium 时不会注册任何相关内容**（物品、配方、附魔均不加载，也不会报错）。

## HUD 与配置

配置文件位于 `config/simpleflightring-client.toml`（客户端配置）：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `showFlightTimer` | `true` | 是否显示飞行时间倒计时 |
| `hideWhileChatOpen` | `true` | 打开聊天框输入时是否隐藏倒计时（默认位置与聊天框重叠，建议保持开启） |
| `hudX` | `4` | 倒计时水平位置：距屏幕左边缘的像素（滑块范围 0~4096） |
| `hudY` | `4` | 倒计时垂直位置：距屏幕底部边缘的像素（滑块范围 0~4096） |

- 默认显示在**左下角**（`hudX=4, hudY=4`），调大 `hudY` 可向上移动。
- 倒计时显示格式为「飞行时间：X 分 Y 秒」；持有**多枚戒指**（饰品槽位 + 背包 + 副手）时，
  剩余飞行时间会**累加**显示。
- 打开聊天框输入文字时倒计时自动隐藏（可在配置中关闭此行为），避免遮挡聊天输入。
- 安装 [Cloth Config API](https://modrinth.com/mod/cloth-config)（15.x，1.21.1）后，
  打开游戏内 Mod 列表 → 简易飞行戒指 → 「Config」即可用开关与滑块条调整上述选项并保存。
- 安装 [Curios API](https://modrinth.com/mod/curios) 与 Cloth Config 均为可选项，MOD 单独运行不受影响。

## 各材质飞行时间

| 材质 | 总飞行时间 | 耐久值 | 附魔能力 |
|------|-----------|--------|---------|
| 木 | 5 分钟 | 300 | 10 |
| 石 | 15 分钟 | 900 | 5 |
| 铁 | 30 分钟 | 1800 | 14 |
| 金 | 60 分钟 | 3600 | 22 |
| 钻石 | 120 分钟 | 7200 | 10 |
| 下界合金 | 240 分钟 | 14400 | 15 |

> 耐久值 = 飞行分钟数 × 60（每飞行 1 秒消耗 1 点耐久）；
> 耐久 III 时各戒指实际可用时间约为上表的 4 倍（再加上经验修补可无限续航）。

## 遗迹飞行戒指（只能捡到损坏版）

八枚主题戒指，**没有任何合成配方**：只能先拿到它们的**损坏版**，再在工作台修复。
损坏版每个符合条件的箱子 **2%** 概率开出（**矿工戒指 4%**；绿宝石戒指不走战利品，
改由大师级图书管理员出售，且**每只管理员只有 50% 概率**刷出该交易）。

| 戒指 | 获取途径（每箱 2%，矿工 4%） | 修复材料 | 飞行时间 | 耐久 |
|------|--------------------|---------|---------|------|
| 幽匿飞行戒指 | 远古城市宝箱 | 见下方任务链 | 120 分钟 | 7200 |
| 矿工飞行戒指 | 废弃矿井箱子 / 箱子矿车 | 见下方任务链 | 30 分钟 | 1800（自带耐久 I） |
| 绿宝石飞行戒指 | **大师级图书管理员**（32 绿宝石，3 次，50% 概率） | 见下方任务链 | 60 分钟 | 3600（自带效率 I） |
| 海洋飞行戒指 | 沉船宝箱（宝藏箱与补给箱） | 见下方任务链 | 120 分钟 | 7200 |
| 荒漠飞行戒指 | 沙漠神殿宝箱 | 见下方配方（青金石 + 金锭） | 30 分钟 | 1800 |
| 劫掠飞行戒指 | 掠夺者哨塔 / 林地府邸宝箱 | 见下方任务链（+ 不死图腾） | 140 分钟 | 8400 |
| 炼狱飞行戒指 | 下界要塞宝箱 | 见下方任务链（岩浆淬火） | 200 分钟 | 12000 |
| 末影飞行戒指 | 末地城宝箱 | 潜影壳 | 240 分钟 | 14400 |

- 损坏戒指是**独立物品**（`damaged_<主题>_flight_ring`）：不能飞行、放不进 Curios 饰品槽、也无法附魔；
  tooltip 会写明需要什么材料修复。
- 修复配方是**工作台无序合成**：损坏戒指 + 1 个对应主题材料 → 完好的戒指，之后与普通戒指完全一致
  （可附魔、可放 Curios 槽、可再用「不毁核心」变成不毁）。幽匿 / 矿工 / 绿宝石 / 海洋 / 劫掠 / 炼狱六枚改走任务链，
  **荒漠戒指没有任务链但配方是摆位合成**（见下方荒漠戒指一节）。
- 掉落概率是**每次开箱独立判定**，在原本的战利品之外额外掉落。

### 幽匿戒指的任务链（与其他七枚不同）

幽匿戒指不走"损坏 + 材料"的普通修复，而是一条两段式任务：

1. 刚拿到时 tooltip 为灰色**「戒指已失去了远古的力量」**+ 幽匿蓝**「戒指在渴望监守者的灵魂」**；
2. **携带这枚戒指击杀监守者**（背包 / 副手 / Curios 槽都算）——一只监守者只对应一枚戒指，
   多枚损坏戒指需要分别去杀各自的监守者。吞噬灵魂后戒指**带附魔光效**，第二行变为幽匿蓝
   **「戒指需要一个新的躯壳」**；
3. 在工作台用**围一圈 8 个回响碎片 + 中间那枚已充能的戒指**合成完整的幽匿飞行戒指。

> 只有"已充能（吞噬过灵魂）"的损坏戒指才能参与该配方，未充能的放上去不出货；配方在 JEI 里可查。
> 已充能的损坏戒指**不会出现在创造模式物品栏**（它是任务进度，不是可以直接拿的物品）。

### 矿工戒指的任务链（同样两段式）

1. 刚拿到时 tooltip 为淡灰**「不知是哪一任矿工留下的戒指」**、淡灰**「斑驳的材质诉说着它早已损坏」**、
   白色**「需要使用爆破的力量重塑」**；
2. **把这枚损坏戒指扔在地上、让一次爆炸波及它**（TNT、苦力怕、其他模组的爆炸都行）——戒指会被
   "爆破重塑"：**自身不会被炸毁**，开始**带附魔光效**，第三行变为白色**「只需再填补材料就能恢复如初」**；
3. 在工作台用**围一圈 8 个铁锭 + 中间那枚已重塑的戒指**合成完整的矿工飞行戒指。

> 矿工戒指耐久对标铁戒指（30 分钟 / 1800），但**自带耐久 I**（内置附魔，砂轮洗不掉，tooltip 显示"自带 耐久 I"），
> 因此实际续航约为 60 分钟。

### 绿宝石戒指的任务链（同样两段式）

1. 刚拿到时 tooltip 为淡灰**「昔日英雄早已离去」**、淡灰**「斑驳的戒指铭刻着的英雄二字」**、
   淡灰**「它诉说着以往的光辉事迹」**、白色**「再守护一次村庄来唤醒它吧」**；
2. **带着这枚损坏戒指赢得一场袭击（Raid）**——背包 / 副手 / Curios 槽都算，戒指
   **带附魔光效**，第四行变白**「戒指感受到了昔日的光辉(I~V)」**并追加第五行**「现在需要重铸一份新的媒介」**
   （一场胜利只作用于**一枚**戒指，同时带多枚要各打一场）；
3. 在工作台用**围一圈 8 个绿宝石 + 中间那枚已唤醒的戒指**合成完整的绿宝石戒指。

**戒指强度 = 那场袭击的不祥之兆等级（I~V）**，与原版村庄英雄的 1~5 级一一对应：

- 带损坏戒指打**几级**袭击，唤醒后括号里就是**几**，合成出的成品戒指也提供**同等级**的村庄英雄
  （等级会跟着戒指穿过工作台：合成时从损坏戒指带过去）；
- **已经唤醒或已经合成的戒指可以继续变强**：在**更高等级**的袭击中获胜就把它的等级提升到那场袭击的等级
  （同级或更低不会有变化），动作栏提示「戒指从这场胜利中汲取了更耀眼的光辉(I~V)」；
- **已经是 V 级**（袭击能给的最高等级）的戒指**不会吸收这场胜利**，会**顺延给其他戒指**
  （先补一次沉睡的损坏戒指，再看有没有等级更低的）；一枚符合条件的都没有时，这场胜利就什么都不做，
  庆祝期内拿到新戒指仍然有效；
- **唤醒优先于升级**：只要身上还有沉睡的损坏戒指，这场胜利就用来唤醒它；
- 合成用的**新配方类型 `simpleflightring:emerald_forge`** 会在合成台里**直接预览出正确等级**
  （合成台的预览就是按配方 `assemble` 算的），取出前后一致。

> 绿宝石戒指耐久对标金戒指（60 分钟 / 3600），并**自带效率 I**（内置附魔，砂轮洗不掉）。
> 损坏版只能从大师级图书管理员手里买（32 绿宝石 / 3 次），且**每只管理员只有 50% 概率**刷出这笔交易
> （晋升大师时判定一次，没出就换一位）。**创造模式物品栏和 `/give` 拿到的成品戒指是满级（V）**。

### 绿宝石戒指的能力「新秀英雄」

能力是**纯被动**的，戴上戒指（Curios 飞行戒指槽）即生效，耐久耗尽或摘下立刻失效：

| 效果 | 说明 |
|------|------|
| 村庄英雄 I~V | 等级 = 戒指充能时那场袭击的等级；30 秒 buff 每秒续，HUD 图标常驻不闪烁 |
| 对灾厄村民伤害翻倍 | 掠夺者 / 卫道士 / 唤魔者 / 劫掠兽 / 幻术师 / 女巫，近战与弓箭都算 |
| 击杀灾厄村民掉落翻倍 | 在原版抢夺结算之后翻倍，**与抢夺附魔叠加**；单件掉落也真的掉两份 |
| 敌对生物掉绿宝石 | 击杀僵尸 / 骷髅 / 蜘蛛等任意敌对生物有 **10%** 概率额外掉 1 个绿宝石（遵循 `doMobLoot` 规则） |

> 因为没有主动能力，绿宝石戒指**吃不到「能量迸发」附魔**，按下能力键也只会提示
> 「新秀英雄 没有主动能力」（与其它纯被动戒指一致）。

### 海洋戒指的任务链（十字形配方）

1. 刚拿到时 tooltip 为淡灰**「古老的力量仍抵不过海水的侵蚀」**、淡灰**「但沉睡的守护者仍在等待适格者」**、
   青色**「击败古老的守卫来向它证明」**；
2. **带着这枚损坏戒指击杀一只远古守卫者**（海底神殿；背包 / 副手 / Curios 槽都算）——戒指得到
   **沉睡的守护者的认可**、**带附魔光效**，第二条变为青色**「沉睡的守护者认可了你」**、第三条变为青色
   **「使用海洋的至宝来恢复远古的力量」**（一只远古守卫者只祝福**一枚**戒指）；
3. 在工作台按**十字形**摆放合成：**中间**放已祝福的损坏戒指、**上**=海洋之心、**左右**=海晶碎片、
   **下**=鹦鹉螺壳 → 海洋飞行戒指。

> 海洋戒指耐久对标钻石戒指（120 分钟 / 7200）、附魔值 12，贴图是**32 帧动态水材质**（与原版水同步）。

### 荒漠戒指的修复（唯一没有任务链的一枚）

1. 刚拿到时 tooltip 为淡灰**「漫天黄沙见证了这片大地的历史」**、淡灰**「它也在时间的流逝下锈蚀损坏」**、
   土黄**「只需一些简单的打磨和修缮」**；
2. **不需要任何前置条件**：直接在工作台摆 **中间**=损坏的戒指、**上下左右**=青金石、**四角**=金锭
   → 荒漠飞行戒指（这是全遗迹里最简单的一档维修）。

> 荒漠戒指耐久对标铁戒指（30 分钟 / 1800）：它的能力偏功能向，所以给的是最低一档的耐久。

### 荒漠戒指的能力「生存主义者」

纯被动，戴上戒指（Curios 飞行戒指槽）即生效，耐久耗尽或摘下立刻失效：

| 效果 | 说明 |
|------|------|
| 幸运 +1 | **真·属性加成**（`Attributes.LUCK`），幸运药水/效果的等级**照常叠加**在上面；钓鱼与箱子战利品都吃这个总幸运值 |
| 免疫中毒与饥饿 | 两种效果**无论来源**都挂不上（药水 / 洞穴蜘蛛 / 腐肉 / 其他 mod 都算）；戴上前已有的也会被清掉 |
| 食物饱食度 +50% | 一切食物多给一半饱食度（金苹果 4 → 6），饱和度按原版比例同步 |
| 危险感知 | 半径 **32 格**内的生物**只对你本人**描边：**友好 / 中立 = 白框**，**正在与你为敌 = 红框**（不加 buff、不发效果，其他玩家看不到） |

> 红框按**行为**判定，不按生物类别：**正在追杀你**（僵尸 / 骷髅 / 苦力怕 / 铁傀儡，也包括猪灵、疣猪兽、监守者这些

> 被记仇（1.21.1 由 `EntitySelector` 过滤、26.1.2 在 `updatePersistentAnger` 里直接清掉仇恨），和平难度同理 ——

> 或打一下中立生物（僵尸猪灵 / 狼 / 蜜蜂…）让它记仇。

## 戒指能力键（默认 V）

- 新增按键绑定「触发戒指能力」，默认 **V**，位于「按键设置 → 杂项」，可自由改键。
- 用于触发**主动**能力：幽匿戒指的音波、矿工戒指的爆破；纯被动能力的戒指按下只会提示「XX 没有主动能力」。

## 与 Allthemodium 联动（可选）

> 仅在安装了 [Allthemodium](https://modrinth.com/mod/allthemodium) 时注册；未安装时下列内容全部不存在，也不会产生任何报错。

| 戒指 | 能量池 | 继承的能力 |
|------|--------|-----------|
| ATM 飞行戒指 | 100 | 魔法内衬 |
| 振金飞行戒指 | 300 | 魔法内衬 + 动能偏转 |
| 难得素飞行戒指 | 700 | 魔法内衬 + 动能偏转 + 爆裂图腾 |

- 三枚联动戒指**合成即不毁**（无需再消耗不毁核心）；但升级链的起点——下界合金戒指——必须**先**用**不毁核心**（1 下界合金锭 + 1 下界之星，无序合成）在锻造台变为不毁。
- 属性（护甲、韧性、攻击力、触及距离）与特殊能力**仅在佩戴于 Curios 饰品槽时生效**；放在背包里只保留飞行。
- 能力沿链条继承：ATM ⊂ 振金 ⊂ 难得素。

### 联动戒指合成（锻造台）

| 产物 | 模板 | 基础 | 追加材料 |
|------|------|------|---------|
| ATM 飞行戒指 | ATM 升级锻造模板 | 不毁的下界合金飞行戒指 | ATM 锭 |
| 振金飞行戒指 | 振金升级锻造模板 | 不毁的 ATM 飞行戒指 | 振金锭 |
| 难得素飞行戒指 | 难得素升级锻造模板 | 不毁的振金飞行戒指 | 难得素锭 |

### 能量与能力

- 能量池被能力消耗后，**最后一次消耗的 10 秒后**开始回复，无论上限多少都在 3 秒内回满；期间再次受伤会打断回复。
- HUD 能量条在回满并静止 3 秒后自动隐藏，数值变化时重新出现。
- **魔法内衬**（ATM）：伤害按 1:1 由能量抵挡；能量足够覆盖整次伤害时直接取消该次伤害（无击退、无红闪、不进入无敌帧）。
- **动能偏转**（振金）：来袭弹射物会被身周球形立场随机弹开，能量高于一半时不消耗能量，低于一半则失效并交由魔法内衬抵挡。
- **爆裂图腾**（难得素）：受到致命伤害时取消该次伤害并像图腾一样复活（回血、清除负面效果、给予生命恢复 II / 伤害吸收 II / 抗火），同时引发一次 8 格、20 点伤害的 TNT 式爆炸（不破坏方块，附带击退）。之后能量回复延迟变为 60 秒，且必须完全回满才能再次触发。

### 魔能增幅（附魔）

仅可附魔在三枚联动戒指上的附魔台附魔，等级 1~9：**能量上限 = 基础能量 × (等级 + 1)**
（例如难得素戒指 9 级时为 7000 点）。同样会出现在村民交易与战利品中。

- 创造/旁观模式的玩家不会消耗戒指耐久（本来就能飞）。
- 戒指耐久耗尽后保留在背包/槽位中（不碎裂），方便升级与修复。
- Curios 槽位采用数据包 JSON 方式注册（Curios 9.x 推荐方式），
  槽位 id 为 `flight_ring`，物品需属于标签 `curios:flight_ring` 才能放入。
